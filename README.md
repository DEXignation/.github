# .github

This is the **organization-default repository** for the
[DEXignation](https://github.com/DEXignation) GitHub organization. It
holds files that GitHub displays at the organization level or that
other DEXignation repositories inherit by default.

본 저장소는 [DEXignation](https://github.com/DEXignation) GitHub 조직의
**기본 저장소**입니다. GitHub이 조직 단위로 노출하거나, 다른 DEXignation
저장소가 기본값으로 상속하는 파일을 담습니다.

---

## Files / 파일

| Path | Purpose | 역할 |
|---|---|---|
| `profile/README.md` | Org profile shown at github.com/DEXignation | github.com/DEXignation에 노출되는 조직 프로필 |
| `SECURITY.md` | Org-wide security policy | 조직 차원 보안 정책 |
| `CODE_OF_CONDUCT.md` | Community code of conduct | 커뮤니티 행동 강령 |
| `FUNDING.yml` | GitHub Sponsors / funding config | GitHub Sponsors / 후원 설정 |
| `ISSUE_TEMPLATE/` | Default issue templates | 기본 이슈 템플릿 |
| `PULL_REQUEST_TEMPLATE.md` | Default PR template | 기본 PR 템플릿 |

These files are public-facing. Do not include any secrets, internal
URLs, or pre-launch business details here.

본 파일들은 공개됩니다. 시크릿, 내부 URL, 출시 전 사업 세부사항을 포함하지
마세요.
